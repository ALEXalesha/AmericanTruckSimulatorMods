Мастерская Steam: как загрузить 10 модов OpenRoad для American Truck Simulator

Загружать может только владелец аккаунта Steam, в котором куплена ATS. Каждый мод -
НОВЫЙ предмет Мастерской (Create new), не Update: моды ETS2 - другие предметы.

Один раз:
1. Steam -> Библиотека -> над списком игр фильтр «Игры» -> отметить «Инструменты».
2. В поиске библиотеки набрать «Workshop Uploader», выбрать загрузчик SCS
   (SCS Workshop Uploader), «Установить», потом «Играть» (запустить).

Для каждого мода (папки лежат рядом с этим файлом, NN_OpenRoad_<Имя>):
1. В загрузчике выбрать игру American Truck Simulator.
2. Нажать «Create new» (New, создать новый).
3. Mod data folder (папка мода): папка upload внутри NN_OpenRoad_<Имя>.
   Именно upload, не universal.
4. Preview image (превью): preview.jpg из той же NN_OpenRoad_<Имя>.
5. Title (название): строка после «TITLE» в steam_page.txt (таблица ниже).
6. Description (описание): открыть steam_description.txt, Ctrl+A, Ctrl+C, вставить.
   Там английский текст, потом русский - так и оставить.
7. Tags (тег типа): из таблицы ниже (или TYPE TAG в steam_page.txt).
8. Visibility (видимость): для первой загрузки Private (скрытый).
9. Change note (заметка): «1.0.0 - first release for ATS 1.61».
10. Нажать «Upload». Если Steam попросит принять соглашение Мастерской - принять
    (это делается один раз на аккаунт). Дождаться «Upload finished».

Проверка и открытие:
1. Подписаться на свой скрытый мод, включить в Менеджере модов. Локальный
   .scs с той же функцией (из папки mod) выключить, чтобы мод не работал дважды.
2. Если всё работает - на странице мода в Steam (или Update в загрузчике)
   поставить видимость Public (всем) или Friends only (друзьям).

Порядок в Менеджере модов: 01 сверху, 10 снизу. 02 Super Power выключить, если
включён 01 Hyper Power. Подробнее - WORKSHOP.md в репозитории.
